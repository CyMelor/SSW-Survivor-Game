# SSW-Survivor-Game

一个幸存者小游戏[测试阶段]。

## 游戏功能

- **角色控制**：使用WASD键控制角色移动
- **射击系统**：自动朝鼠标方向发射子弹
- **敌人AI**：敌人从屏幕随机生成并向玩家移动
- **游戏控制**：Q键暂停/继续游戏，R键重启游戏
- **生命值显示**：[测试阶段]生命值表示被攻击到的次数

## 项目结构

```
ssw-Game/
├── css/
│   └── style.css          # 游戏样式文件
├── html/
│   └── index.html         # 游戏主页面
├── js/
│   └── game.js            # 游戏核心逻辑
├── app.py                 # 服务器启动脚本
└── README.md              # 项目说明文档
```

## 如何运行

1. 直接在浏览器中打开 `html/index.html` 文件
2. 或使用 Python 运行服务器脚本：
   ```bash
   python app.py
   ```
   然后在浏览器中访问 http://localhost:15000
